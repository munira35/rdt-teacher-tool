# أداة المعلمة · مشروع التقليل من الأدوات الرقمية

أداة تعمل بالكامل في متصفح المعلمة: تنظيم صور الأدلة وتغطية أسماء الطالبات، وتعبئة تقرير المعلمة (Word) من اختيارات فقط، وتجهيز ملف الرفع إلى الون درايف.

**الخصوصية:** لا تُرسل الأداة أي صورة أو بيانات إلى أي خادم. كل شيء يبقى على جهاز المعلمة حتى ترفعه بنفسها إلى الون درايف.
